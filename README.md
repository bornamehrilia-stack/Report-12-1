# 📋 گزارش پروژه: کنترل رله با آردوینو (Arduino Relay Control)

## ۱. مقدمه  
در این پروژه, یک **ماژول رله 1 کاناله** به آردوینو متصل شده است و با فراخوانی `digitalWrite()`, رله به صورت دوره‌ای روشن و خاموش می‌شود..



---

## ۳. قطعات مورد استفاده  
- برد آردوینو Uno  
- ماژول رله 1 کاناله  
- یک LED سبز (در ماژول رله وجود دارد — برای نمایش وضعیت)  
- برد برد و سیم‌های جامپر  




---

## ۵. کد برنامه 

```cpp
int RelayPin = 6;  // پین کنترل رله

void setup() {
  pinMode(RelayPin, OUTPUT);  // تنظیم پین به عنوان خروجی
}

void loop() {
  // روشن کردن رله (فعال کردن رеле)
  digitalWrite(RelayPin, LOW);  // LOW = رله فعال
  delay(3000);               // 3 ثانیه

  // خاموش کردن رله (غیرفعال کردن رله)
  digitalWrite(RelayPin, HIGH); // HIGH = رله غیرفعال
  delay(3000);                // 3 ثانیه
}
```
---

## ۶. نحوه‌ی کارکرد  
1. پس از آپلود کد, رله هر 3 ثانیه یکبار فعال و غیرفعال می‌شود:  
   - 3 ثانیه: رله **فعال** → LED سبز روشن  
   - 3 ثانیه: رله **غیرفعال** → LED سبز خاموش  
2. این چرخه به صورت بی‌پایان تکرار می‌شود.
.

## ۷. نتایج  
- رله به درستی کار می‌کند (LED سبز روشن/خاموش می‌شود).
